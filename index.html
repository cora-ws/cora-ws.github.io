Cora

Usa os serviços de API do YouTube (YouTube API Services).

Cora é a ferramenta pessoal de automação de Giovanni Giampauli. Ela não é um produto aberto ao público e não tem usuários externos.

Uma das funções da Cora é publicar e organizar vídeos nos canais do YouTube que pertencem ao próprio Giovanni: envio de vídeos, envio de miniaturas, atualização de título, descrição e metadados, e leitura das estatísticas desses mesmos canais.

A Cora não acessa canais, contas ou dados de outras pessoas.
